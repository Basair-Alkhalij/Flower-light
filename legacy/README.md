# ملفات قديمة للمرجع فقط

هذا المجلد أرشيف لإصدارات وتقارير وترقيات سابقة حتى v109. لا تُستخدم ملفاته في نشر جديد ولا تُشغَّل ملفات SQL منه على قاعدة حية إلا عند مراجعة تاريخ ترقية قاعدة بعينها.

المسار المعتمد حاليًا:

- قاعدة أقدم من v105: `supabase/UPGRADE_EXISTING_V105.sql` ثم `supabase/UPGRADE_EXISTING_V110.sql`.
- قاعدة v105 أو أحدث: `supabase/UPGRADE_EXISTING_V110.sql` فقط.
- `supabase/migrations/` يحتفظ بالمهاجرات الأصلية كسجل تاريخي.

ملفا v106 وv108 المتكرران نُقلا إلى `legacy/sql/` لأن محتواهما مطابق للمهاجرات الأصلية، لتجنب وجود مسارين نشطين لنفس التغيير.
