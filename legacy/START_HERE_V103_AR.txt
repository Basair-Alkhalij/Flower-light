بصائر الخليج — تحديث v103
========================

هذه النسخة مبنية مباشرة على v102، ولا تضيف جداول SQL جديدة.

أهم التغييرات:
- ترتيب لوحة المدير: الرئيسية أصبحت ملخصاً وإحصائيات واختصارات فقط.
- صفحات مستقلة للمالك: إعدادات الموقع، بيانات الشركة، قالب المنتجات.
- نقل البريد الأساسي للاستعادة إلى صفحة بيانات تسجيل الدخول.
- تنظيم قائمة لوحة المدير إلى مجموعات واضحة.
- إصلاح مقاسات قائمة إضافة السعر على اللابتوب والتابلت والجوال.
- رفع مقاسات أزرار الحذف/التعديل/السحب لتكون أسهل باللمس.

إذا كانت قاعدة البيانات عندك على v102:
1) لا تحتاج تشغيل SQL جديد لهذه النسخة.
2) ارفع ملفات v103 واستبدل الملفات السابقة.
3) تأكد من رفع index.html وstyle.css وadmin.js وadmin-settings.js وadmin-business.js وبقية ملفات المشروع مع sw.js وmanifest.webmanifest.
4) إذا كنت ترفع مجلد dist بدلاً من ملفات المصدر، استخدم مجلد dist الموجود داخل هذه النسخة فقط لأنه أُعيد بناؤه لـ v103.
5) بعد الرفع افتح الموقع بتحديث قوي Ctrl+F5 أو امسح كاش الموقع إذا بقيت نسخة قديمة.

إذا كنت قادماً من v101 أو أقدم:
- طبّق تحديثات قاعدة البيانات السابقة أولاً حسب START_HERE_V102_AR.txt وUPGRADE_V102.sql.

فحوصات النسخة:
- npm run test:static : ناجح.
- npm run build:check : ناجح.
- npm run build : ناجح.
- فحص Chromium للمقاسات 1280 / 768 / 390 / 360 : ناجح لصفوف الأسعار وأزرار المدير وعدم وجود تجاوز أفقي في نموذج الفحص.
